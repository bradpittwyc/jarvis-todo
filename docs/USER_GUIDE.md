# 用户手册

## 开始使用

安装后从桌面或开始菜单打开 **Jarvis Todo**。左侧是智能列表与自定义列表，中间显示当前列表的任务，点击任务会打开右侧详情面板。

## 管理任务

- 在底部“添加任务”输入框输入内容并按 Enter 创建任务。
- 点击任务左侧圆圈完成或恢复任务。
- 点击右侧星标将任务设为重要。
- 在任务详情中添加步骤、截止日期、提醒、重复规则和备注。
- 使用左侧搜索框按标题过滤任务。

## 列表与主题

点击“新建列表”创建个人列表。点击页面右上角 `•••` 可切换主题、打印当前列表或发送给 Jarvis。

## 打印

选择“打印列表”后，应用使用 A4 双栏清单版式。未完成与已完成任务分别展示，单页可容纳更多待办。

## 自动升级

安装版启动约三秒后会检查 GitHub Releases。发现新版本后自动下载，完成时提示是否重启安装。也可通过应用菜单“帮助 → 检查更新”手动检查。

## 数据保存

所有更改会自动保存到本机。升级应用不会覆盖任务数据。
